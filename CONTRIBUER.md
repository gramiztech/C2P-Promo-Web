# Comment contribuer à ce dépôt

## Toi qui fais partie d'une équipe du dimanche

Les équipes changent chaque semaine, donc chaque équipe part d'un dossier neuf.

1. Dans `ateliers/`, crée un dossier avec la date du jour, format `AAAA-MM-JJ` (par exemple `2026-09-07`).
2. Dedans, crée un dossier par équipe : `equipe-1`, `equipe-2`, etc.
3. Copie le contenu de `ateliers/modele-equipe/` dans ton dossier d'équipe, et remplis-le.
4. À la fin de l'atelier, ton dossier doit contenir au minimum :
   - qui était dans l'équipe ce jour-là
   - ce que vous avez essayé de faire
   - ce qui a marché, ce qui n'a pas marché
   - le code, s'il y en a

Personne ne juge un atelier râté. Un atelier non documenté, par contre, ça n'a servi à personne d'autre que vous.

## Toi qui prépares une séance

1. Crée un dossier dans `cours/`, nommé `seance-NN-sujet` (par exemple `seance-03-flexbox`).
2. Mets un `README.md` avec : l'objectif de la séance, ce qui a été couvert, et un lien vers les ressources utilisées.
3. Range les fichiers (PDF, images, exemples de code) dans un sous-dossier `ressources/`.

## Format des commits

Rien de compliqué : une phrase courte, en français, qui dit ce que tu as fait.
```
ajoute le README de l'équipe 2 du 07/09
corrige une faute dans la séance CSS
```
