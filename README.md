# C2P — Promo Développement Web

Ce dépôt regroupe tout ce qui concerne la formation : les cours, les ressources, et le travail de chaque équipe des ateliers du dimanche.

## Comment le dépôt est rangé

```
c2p-promo-devweb/
├── cours/              → les séances du vendredi, une par dossier
├── ressources-externes.md  → liens choisis pour aller plus loin
├── ateliers/            → le travail de chaque équipe, par dimanche
└── projet-final/        → le site officiel de C2P, le vrai projet de la promo
```

## Si tu cherches un cours

Va dans `cours/`. Chaque séance a son propre dossier (`seance-01-html`, `seance-02-css`...), avec un README qui résume ce qu'on a vu, et un dossier `ressources/` pour les PDF, images ou fichiers utilisés pendant le cours.

## Si tu cherches le travail d'une équipe

Va dans `ateliers/`. Les équipes changent chaque dimanche, donc on range par date, pas par nom d'équipe fixe. Le dossier `ateliers/modele-equipe/` contient un modèle à copier — voir `CONTRIBUER.md` pour la marche à suivre.

## Si tu veux voir le vrai site

Le dossier `projet-final/` contient le site officiel de C2P, celui qui sera mis en ligne à la fin de la promo. C'est le même code que celui qu'on construit ensemble en séance.

## Une règle simple

On documente au fur et à mesure, pas à la fin. Un README écrit une semaine après coup, personne ne s'en souvient assez bien pour bien l'écrire.
