# Séance 2 — Mettre en forme avec CSS

**Date :** 28 août 2026

## Ce qu'on a vu

- Pourquoi le CSS existe, et comment le relier à une page HTML
- Le vocabulaire de base : sélecteur, déclaration, propriété, valeur
- Les sélecteurs (élément, classe, id), la cascade et la spécificité
- Le modèle de boîte (box model) et le piège du `width` + `padding`
- Les unités, les couleurs, la typographie de base
- `display` et `position`, en survol
- Les pseudo-classes, les pseudo-éléments, et une première media query
