Comment on apprend chez C2P

Du béton au code

On enseigne la structure avant le style : le HTML, ce sont les fondations et les briques, le CSS c'est la peinture. On ne peint jamais un mur qui n'est pas encore monté.

Le rythme des Vendredis Code

Une séance le vendredi pour apprendre une notion, un atelier le dimanche pour la pratiquer en équipe, sur six séances.

Ancré dans notre quotidien

Les exemples viennent d'ici : le maquis, le marché d'Assigamé, nos plats. Le code s'apprend mieux quand il parle de ce qu'on connaît déjà.
