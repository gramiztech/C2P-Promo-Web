A propos de C2P

Pourquoi cette communauté

C2P, la Communauté Premiers Pas, est née pour donner un premier vrai point d'entrée dans le développement web à Lomé : un endroit où apprendre les bases sérieusement, sans se perdre dans le jargon.

Notre méthode

On enseigne dans l'ordre : d'abord la structure d'une page (le HTML, les fondations), ensuite seulement la mise en forme (le CSS, la peinture). On avance par séances le vendredi, puis on met la main à la pâte lors d'un atelier le dimanche.

Le format

Le programme "Les Vendredis Code" suit une promotion sur six séances, du premier contact avec le HTML jusqu'à la mise en ligne d'un vrai projet.
